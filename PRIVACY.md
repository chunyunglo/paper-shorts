# Privacy Policy / 隱私權政策

Last updated: 2026-10-25

**Behavior Decode Uploader** is a personal automation tool operated by the owner of the Human Behavior Decode channel. It is used only by its owner to upload videos to the owner's own YouTube channel and to read and reply to comments on those videos.

- Data accessed: the owner's YouTube channel information, uploaded videos, and public comments on those videos.
- Use: comments are read to post replies, hide spam, and alert the owner about comments that need personal attention. Comment text may be sent to the Anthropic API for classification and reply drafting.
- Storage: no personal data of commenters is sold or shared with third parties beyond the processing above. Logs record only counts, not comment content.
- Google user data is used in accordance with the Google API Services User Data Policy, including the Limited Use requirements.
- Contact: open an issue at https://github.com/chunyunglo/paper-shorts/issues

**Behavior Decode Uploader** 是頻道擁有者自用的自動化工具，只用來上傳影片到自己的 YouTube 頻道，並讀取與回覆影片下的公開留言。留言內容可能送至 Anthropic API 進行分類與草擬回覆；不會出售或分享留言者資料，執行紀錄只記錄數量，不記錄留言內容。
